# Environment Variables Example

This file lists the environment variables required to configure the MaVidhai backend.

Copy the variable names into your local `.env` file and replace the placeholder values with your own configuration. Never commit real credentials or secrets to GitHub.

## Configuration

DATABASE_URL=your_database_connection_string

FRONTEND_URL=http://localhost:3000

GOOGLE_CLOUD_PROJECT_ID=your_google_cloud_project_id
GOOGLE_CLOUD_LOCATION=your_google_cloud_location

RAZORPAY_KEY_ID=your_razorpay_test_key_id
RAZORPAY_KEY_SECRET=your_razorpay_test_key_secret
RAZORPAY_WEBHOOK_SECRET=your_razorpay_test_webhook_secret

JWT_SECRET_KEY=replace_with_a_secure_local_development_secret
JWT_ALGORITHM=HS256
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=30
## Setup

1. Create a local `.env` file in the backend's expected configuration directory.
2. Copy the variables above into it.
3. Set the values required for your local environment.
4. Use test credentials for payment development.
5. Keep `.env` out of version control.
